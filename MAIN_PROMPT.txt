PROJECT PURPOSE AND HOW TO APPLY THIS BRIEF
SHARAY is a defensive security assessment workspace for security engineers working on systems they own or have explicit permission to assess. It brings target authorization, established assessment tools, evidence review, remediation and reporting into one authenticated desktop experience. Its purpose is to help operators understand and fix security issues using reproducible observations and controlled checks.

The intended operator flow is: sign in, create a project, register and verify targets, approve an exact scope and profile, launch a permitted assessment, watch real progress and events, review findings and evidence, generate reports, then track fixes and retest. The backend owns authorization, policy decisions, jobs and stored records. Scanner workers perform only approved checks through typed adapters. The optional AI helps explain evidence and propose bounded investigations; deterministic policy controls execution. The no-LLM workflow remains required.
