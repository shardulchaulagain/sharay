## 3. How to Reproduce These Results

To reproduce the exact numbers above on any workstation or CI runner:

```bash
# 1. Run the evaluation benchmark engine (writes tests/evaluation/lab/benchmark_results.json)
.venv/bin/python -m packages.evaluation_lab

# 2. Run the integration test suite for the evaluation lab
.venv/bin/python -m unittest tests/evaluation/lab/test_lab_corpus.py -v

# 3. Run AutoPyVerifier live fixture proof test
.venv/bin/python -m unittest tests/product/test_autopyverifier_consensus.py -v
```
